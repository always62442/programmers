📘 문제 이름

덧셈식 출력하기
- 🧩 난이도: level 0
- 🛠 사용 언어: Python3
- [문제 링크]https://school.programmers.co.kr/learn/courses/30/lessons/181947

🧠 문제 설명

두 정수 a, b가 주어질 때 다음과 같은 형태의 계산식을 출력하는 코드를 작성해 보세요.

a + b = c

---------

💡 아이디어

입력을 공백 기준으로 나눠서 정수로 변환해 a, b에 저장함
print()에 여러 값을 쉼표로 전달하면 사이에 공백이 자동으로 들어가서 "a + b = c" 형식으로 출력됨
