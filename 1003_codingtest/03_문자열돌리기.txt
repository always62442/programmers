📘 문제 이름

문자열 돌리기
- 🧩 난이도: level 0
- 🛠 사용 언어: Python3
- [문제 링크]https://school.programmers.co.kr/learn/courses/30/lessons/181945

---------

🧠 문제 설명

문자열 str이 주어집니다.
문자열을 시계방향으로 90도 돌려서 아래 입출력 예와 같이 출력하는 코드를 작성해 보세요.

---------

💡 아이디어

문자열의 각 글자를 줄바꿈(\n)으로 이어 붙여서 한 글자씩 세로로 출력
"\n".join(str)으로 한 줄에 처리

---------

배운 것, 느낀 점, 아직 이해되지 않은 점 (선택)
>> 반복문 (for 문)
   문자열을 한 글자씩 순회할 때 가장 기본적이고 자주 쓰이는 방법
   파이썬의 문자열은 그 자체로 순회 가능한(iterable) 객체
>> 문자열 결합 메서드 (join)
   리스트나 문자열 사이사이에 특정 문자(여기서는 줄바꿈 문자 \n)를 넣어 하나의 문자열로 합쳐주는 기능
   for 문 대신 한 줄로 깔끔하게 처리할 때 유용함
>> 출력 옵션 (unpacking 활용)
   문자열의 각 문자를 분리하여 print() 함수에 전달하고, 출력 구분자(sep)를 줄바꿈(\n)으로 지정하는 방법

다른 사람의 풀이
>> for char in str:
       print(char)
