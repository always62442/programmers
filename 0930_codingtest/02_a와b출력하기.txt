📘 문제 이름

a와 b 출력하기
- 🧩 난이도: level 0
- 🛠 사용 언어: Python3
- [문제 링크]https://school.programmers.co.kr/learn/courses/30/lessons/181951

---------

🧠 문제 설명

정수 a와 b가 주어집니다. 각 수를 입력받아 입출력 예와 같은 형식으로 출력하는 코드를 작성해 보세요.

---------

💡 아이디어

input().strip().split(' ')으로 입력을 공백 기준으로 나누고 map(int, ...)으로 정수로 변환해서 a, b에 저장함
f-string과 \n을 이용해서 "a = 값", "b = 값" 형식으로 두 줄 출력함

---------

배운 것, 느낀 점, 아직 이해되지 않은 점 (선택)
>> .strip(): 문자열 앞뒤의 공백이나 줄바꿈 문자를 제거함
>> .split(): 공백을 기준으로 문자열을 나눔 (예: ['4', '5'])
