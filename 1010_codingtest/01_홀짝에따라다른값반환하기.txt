📘 문제 이름

홀짝에 따라 다른 값 반환하기
- 🧩 난이도: level 0
- 🛠 사용 언어: Python3
- [문제 링크]https://school.programmers.co.kr/learn/courses/30/lessons/181935

---------

🧠 문제 설명

양의 정수 n이 매개변수로 주어질 때, n이 홀수라면 n 이하의 홀수인 모든 양의 정수의 합을 return 하고 n이 짝수라면 n 이하의 짝수인 모든 양의 정수의 제곱의 합을 return 하는 solution 함수를 작성해 주세요.

---------

💡 아이디어

n % 2로 홀짝을 판별해서 분기
홀수면 range(1, n + 1, 2)로 홀수만 만들어 합을 구하고, 짝수면 range(2, n + 1, 2)로 짝수만 만들어 각각 제곱한 뒤 합을 구함

---------

배운 것, 느낀 점, 아직 이해되지 않은 점 (선택)
>> sum(): 합계 구하기
   반복 가능한 객체(리스트, range 등)의 모든 원소의 합을 반환함
   예) sum([1, 3, 5, 7]) -> 16
>> range(시작, 끝, 간격): 규칙적인 숫자 나열 만들기
   시작부터 끝 전까지 간격만큼 건너뛰며 숫자를 만들어 줌
   끝 값은 포함되지 않아서 n까지 포함하려면 n + 1을 써야 함
   예) range(1, 8, 2) -> 1, 3, 5, 7 / range(2, 11, 2) -> 2, 4, 6, 8, 10
>> 제너레이터 표현식: sum(식 for i in range(...))
   for문으로 값을 하나씩 꺼내 식을 계산한 결과를 바로 sum()에 넘겨주는 문법임
   리스트를 따로 만들지 않고 한 줄로 합을 구할 수 있음
   예) sum(i**2 for i in range(2, 11, 2)) -> 220
>> ** (거듭제곱 연산자)
   예) 3**2 -> 9, i**2 -> i의 제곱
>> % (나머지 연산자)
   n % 2 == 1이면 홀수, n % 2 == 0이면 짝수
