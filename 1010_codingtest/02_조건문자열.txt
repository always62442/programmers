📘 문제 이름

조건 문자열
- 🧩 난이도: level 0
- 🛠 사용 언어: Python3
- [문제 링크]https://school.programmers.co.kr/learn/courses/30/lessons/181934

---------

🧠 문제 설명

문자열에 따라 다음과 같이 두 수의 크기를 비교하려고 합니다.

- 두 수가 n과 m이라면
    - ">", "=" : n >= m
    - "<", "=" : n <= m
    - ">", "!" : n > m
    - "<", "!" : n < m

두 문자열 ineq와 eq가 주어집니다. ineq는 "<"와 ">"중 하나고, eq는 "="와 "!"중 하나입니다. 그리고 두 정수 n과 m이 주어질 때, n과 m이 ineq와 eq의 조건에 맞으면 1을 아니면 0을 return하도록 solution 함수를 완성해 주세요.

---------

💡 아이디어

ineq와 eq의 조합 4가지를 if / elif로 나눠서 각각에 맞는 비교식을 계산함
비교 결과(True / False)를 int()로 감싸서 1 / 0으로 바꿔 return

---------

배운 것, 느낀 점, 아직 이해되지 않은 점 (선택)
>> 비교 연산자 (>=, <=, >, <)
   두 값을 비교해서 True 또는 False를 반환함
   예) 20 <= 50 -> True, 41 > 78 -> False
>> int(True / False): 불리언을 정수로 변환하기
   True는 1, False는 0으로 변환됨
   비교식을 int()로 감싸면 따로 1 / 0을 지정하지 않아도 바로 정답 형태로 return할 수 있음
   예) int(20 <= 50) -> 1, int(41 > 78) -> 0
>> if / elif / else: 여러 조건 분기하기
   위에서부터 차례대로 조건을 검사해서 처음으로 참인 조건의 블록만 실행함
>> and: 두 조건을 모두 만족하는지 검사하기
   양쪽 조건이 모두 참일 때만 참이 됨
   예) ineq == ">" and eq == "="
>> == (같은지 비교)
   문자열도 == 로 같은 문자열인지 비교할 수 있음
